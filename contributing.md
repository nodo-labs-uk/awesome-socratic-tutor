# Contribution guidelines

To add a resource, open a pull request that changes `README.md`.

- Add one line per resource, at the bottom of the section it fits.
- Use the format `- [Name](link) - Description.` The description starts with a capital letter and ends with a full stop.
- Say what the resource is and does, in one or two sentences. Leave out sales words.
- For software, add the language and licence as tags at the end, for example `` `Rust` `MIT` ``.
- Only add projects that are maintained and have documentation.
- Check that the link works.

To fix a dead link or a wrong description, open a pull request or an issue.
